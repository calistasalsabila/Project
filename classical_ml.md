# Roadmap Project Machine Learning (Setelah Classical ML)

> Disusun khusus **sesuai level & tujuan kamu**: kuat di fundamental, relevan buat akademik, dan *bisa naik ke paper*.

---

## Prinsip Urutan Ini

* Dari **paling aman secara konsep** → **paling menantang secara analisis**
* Setiap project **naikkan cara berpikir**, bukan cuma nambah algoritma
* Minimal **1 project siap dinaikkan jadi paper**

---

## Tahap 1 — Validasi Dasar (Cepat tapi Wajib)

### 1️⃣ Fake Product Review / Spam Detection

**Tujuan:** buktiin kamu paham NLP dasar, bukan sekadar pakai library.

* Fokus:

  * Text cleaning (regex, stopwords)
  * Bag-of-Words / TF-IDF
* Algoritma:

  * Naive Bayes
  * SVM
* Output penting:

  * Analisis kata yang paling berpengaruh
  * Error analysis (false positive / false negative)

*Ini fondasi semua NLP selanjutnya.*

---

## Tahap 2 — Cara Berpikir Akademik & Bisnis

### 2️⃣ Student Dropout Prediction   (REKOMENDASI UTAMA)

**Tujuan:** belajar berpikir sebab–akibat, bukan cuma prediksi.

* Fokus:

  * Data tabular
  * Feature importance
  * Interpretasi hasil
* Algoritma:

  * Random Forest
  * XGBoost
* Output penting:

  * Fitur paling berpengaruh terhadap DO
  * Insight kebijakan (apa yang *bisa dilakukan* institusi)

**Project paling aman & kuat untuk paper.**

---

## Tahap 3 — Data Dunia Nyata (Tidak Ideal)

### 3️⃣ Credit Card Fraud Detection

**Tujuan:** naik kelas dari “akurasi tinggi” ke “model berguna”.

* Fokus:

  * Imbalanced data
  * Precision, Recall, F1
  * Threshold tuning
* Algoritma:

  * Logistic Regression (class weight)
  * Isolation Forest
* Output penting:

  * Perbandingan sebelum & sesudah handling imbalance
  * Diskusi trade-off false positive vs false negative

Cocok untuk **comparative paper**.

---

## Tahap 4 — NLP Menengah (Portfolio Kuat)

### 4️⃣ Resume Screening with Machine Learning

**Tujuan:** NLP yang kelihatan "mahal" tapi masih classical.

* Fokus:

  * Text similarity
  * Information retrieval mindset
* Algoritma:

  * TF-IDF
  * Cosine Similarity
* Output penting:

  * Skor kecocokan CV–Job
  * (Opsional) Web app sederhana

Kuat untuk **portfolio + demo**, bukan paper utama.

---

## Tahap 5 — Time Series (Dunia Berbeda)

### 5️⃣ Future Sales Prediction

**Tujuan:** belajar berpikir temporal & hindari data leakage.

* Fokus:

  * Time-based split
  * Lag features
  * Trend & seasonality
* Algoritma:

  * Linear Regression
  * XGBoost Regressor
* Output penting:

  * Perbandingan naive vs ML
  * Analisis kesalahan prediksi waktu tertentu

Nilai plus, tapi **bukan prioritas paper**.

---

## Tahap 6 — Boss Level NLP (Opsional, Paling Berat)

### 6️⃣ Hate Speech Detection

**Tujuan:** stress-test kemampuan NLP kamu.

* Fokus:

  * Slang
  * Ambiguitas label
  * Contextual error
* Algoritma:

  * SVM
  * Random Forest
* Output penting:

  * Error analysis berbasis konteks
  * Diskusi batasan model classical

Cocok kalau target kamu **paper NLP**, tapi berat secara mental.

---

## Rekomendasi Final (Jalur Paling Cerdas)

**Kerjakan semua sebagai latihan**, tapi:

### Untuk Paper:

* **Student Dropout Prediction** (paling stabil & rasional)
* Alternatif: Fraud Detection

### Untuk Portfolio:
