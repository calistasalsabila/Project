## Prinsip Utama Reset

Kalau satu pipeline nyambung, konsep lain bakal ke-recall sendiri.

---

## Urutan Reset Wajib (Pipeline ML Classical)

### 1. Pahami Data Dulu

Sebelum mikir model, pastikan kamu bisa jawab:

* `X` itu apa?
* `y` itu apa?
* Satu baris merepresentasikan apa?
* Setiap kolom artinya apa?

Kalau ini jelas, proses ML tidak akan terasa gelap.

---

### 2. Preprocessing (Inti ML Classical)

Ingat **5 hal ini saja dulu**:

1. Missing value
2. Encoding (Label / One-Hot)
3. Scaling
4. Train–test split
5. Data leakage

Kalau bagian ini masih nyambung, fondasi ML kamu masih ada.

---

### 3. Model = Fungsi Logika

Jangan anggap model sebagai kotak hitam.

Pahami dengan bahasa manusia:

* Logistic Regression → garis pemisah
* Decision Tree → logika if–else
* Random Forest → voting dari banyak if–else

Kalau bisa menjelaskan model tanpa rumus, itu sudah cukup.

---

### 4. Evaluasi yang Relevan

Fokus ke metrik yang benar:

* Classification → Precision, Recall
* Regression → MAE / RMSE

Catatan penting:

* Accuracy sering menipu
* Jangan jadikan accuracy satu-satunya patokan
